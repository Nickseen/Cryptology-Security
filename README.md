# Caesar Cipher Implementation

A Python implementation of the Caesar cipher with advanced features including permutation and brute force attacks.

## Features

- **Basic Caesar Cipher**: Standard encryption/decryption with shift keys (1-25)
- **Caesar Cipher with Permutation**: Enhanced version using keyword-based alphabet permutation
- **Brute Force Attack**: Automated testing of all possible keys
- **Input Validation**: Comprehensive validation for keys and text input
- **Interactive Menu**: User-friendly command-line interface

## Usage

Run the program:
```bash
python main.py
```

The interactive menu provides options for:
1. Basic encryption/decryption
2. Permutation-based encryption/decryption
3. Brute force attacks on encrypted text

## Requirements

- Python 3.x
- No external dependencies required
